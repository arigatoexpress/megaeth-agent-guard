# Roadmap

## Phase 1: Shipped

- Dedicated repo.
- Static MegaETH source catalog.
- Live read-only RPC and Rabbithole scout.
- Intent policy engine.
- Domain spoof guard.
- Dashboard and JSON API.
- CLI and tests.

## Phase 2: MegaETH-Native Depth

- Add WebSocket Realtime API subscriptions for logs, mini-blocks, and selected
  state changes.
- Add source drift detection for docs, Rabbithole app rows, tokenlist, and
  explorer metadata.
- Add unsigned transaction preview adapters for selected app categories.
- Add policy receipts that can be anchored on MegaETH testnet only.

## Phase 3: Sapphire/Satellite Synergy

- Bring in Sapphire-style RWA/cyber signal access as a paid report resource.
- Use x402-style HTTP 402 responses for mock payment-gated reports.
- Keep settlement disabled until explicit operator review.
- Add privacy envelopes inspired by Zama/Aztec: hash commitments and redacted
  witnesses first, live cryptographic integrations later.

## Phase 4: Ecosystem Contribution

- Publish a JSON policy schema for MegaETH app builders.
- Offer a drop-in pre-wallet hook for agent frameworks.
- Add examples for app teams to mark actions as read, quote, simulate, or write.
- Build a public compatibility matrix for agent-safe MegaETH apps.
